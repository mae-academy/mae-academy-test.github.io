# تسليم تحديث ElectroLab Simulator

تم تحديث المشروع ليصبح محاكي دوائر تفاعلياً بواجهة عمل فاتحة ومنطق محاكاة عقدي، مع ربط واجهة التحرير والقياس بالتمثيل الكهربائي الفعلي للدارات المدعومة.

## ما تم تنفيذه

| المجال | التحسينات المنفذة |
|---|---|
| تحرير مساحة العمل | تحديد المكونات والأسلاك والنصوص، التحريك بالماوس أو أسهم لوحة المفاتيح، النسخ والقص واللصق، الدوران والقلب، والتسمية التلقائية الفريدة مثل `V1` و`R1` و`L1` و`DMM1`. |
| الواجهة | النمط الفاتح هو الافتراضي، مع شبكة، التقاط للشبكة، تقريب، تحريك مساحة العمل، ولوحة خصائص سياقية. |
| الأسلاك | التوصيل بالنقر على طرفين، تحديد السلك وحذفه، مسارات مستقيمة أو متعامدة أو يدوية، إضافة نقاط انعطاف وتحريكها، وإظهار الطول الهندسي. لا يؤثر تغيير الشكل الهندسي للسلك في كونه وصلة مثالية صفرية الأوم داخل الحلّال. |
| مصادر وقدرة | مصادر DC وAC، مصدر وRail ثلاثي الطور متزن بأطوار `L1/L2/L3/N`، وRail DC. |
| مكونات وتحكم | مقاومة متغيرة ثلاثية الأطراف، مفاتيح ومفاتيح دفع، ريليهات وكونتاكتورات، وملامسات مساعدة NO/NC قابلة للربط باسم مرجع ملف الريليه أو الكونتاكتور لدارات التحكم الكلاسيكية. |
| العرض | حركة إلكترونات على الأسلاك عند وجود تيار محلول، في الاتجاه العكسي للتيار التقليدي، مع سطوع LED يتناسب مع التيار ولونه المحدد. |
| القياس | DMM متحرك بمسباري HI وCOM فعليين، أوضاع DCV وACV وDCA وACA وOHM، اختيار مدى، حالة تجاوز المدى، وحساب RMS لإشارات AC. يوجد أيضاً راسم ذبذبات متعدد القنوات يعتمد عينات زمنية مرجعية إلى مجسات الأرضي. |
| النصوص | إضافة نصوص حرة داخل مساحة العمل وتحرير محتواها وحجمها ولونها وتحريكها. |

## منطق الحل والتحقق

يعتمد المحرك على تجميع العقد من الأسلاك ثم حلّ المعادلات الخطية للمصادر والمقاومات والمفاتيح والحالات غير الخطية المبسطة. تتم معالجة الملامسات المرتبطة بحالة الملف ضمن تكرار حتى الاستقرار، وتُشتق قراءات الأدوات من فرق الجهد أو تيار الفرع أو عينات الجهد الفعلية، بدلاً من قيم عرض تجريبية.

تم تنفيذ وتشغيل تحقق مرجعي آلي يغطي الحالات الآتية:

| حالة التحقق | نتيجة التحقق |
|---|---|
| مقسم جهد DC | ناجح |
| قراءة DMM للجهد والمقاومة وتجاوز المدى | ناجح |
| قيمة RMS لمصدر AC | ناجح |
| عينات راسم الذبذبات | ناجح |
| مصدر ثلاثي الطور وجهد خط-إلى-خط | ناجح |
| ملامسات التحكم المساعدة | ناجح |
| المقاومة المتغيرة | ناجح |

## التشغيل

بعد فك الضغط وتثبيت الحزم، شغّل الأوامر التالية:

```bash
pnpm install
pnpm validate:simulation
pnpm dev
```

ولإنشاء نسخة إنتاج:

```bash
pnpm build
```

> **ملاحظة عن الدقة:** تم التحقق آلياً وتفاعلياً من الدارات المرجعية والوظائف المدعومة أعلاه. لا ينبغي تفسير ذلك كضمان رياضي مطلق لكل طوبولوجيا أو لكل نموذج مكوّن متقدم غير ممثل تفصيلياً؛ النماذج المتقدمة مثل أشباه الموصلات والآلات والمحولات هي نماذج تعليمية مبسطة ضمن نطاق هذا المحاكي، بينما تُعطى أولوية الدقة للدوائر الخطية ومصادر القدرة والقياس والتحكم المذكورة في الاختبارات.

## الملفات الأساسية المعدلة

- `client/src/pages/Home.tsx`: مساحة العمل والتفاعل والتحرير والقياس.
- `client/src/lib/circuitTypes.ts`: نماذج بيانات الدارات والاختيار والنصوص واللقطات.
- `client/src/lib/wiring.ts`: هندسة وتحرير مسارات الأسلاك.
- `client/src/lib/componentDefs.ts`: تعريفات المكونات الجديدة والأطراف.
- `client/src/lib/symbols.tsx`: رموز SVG ومؤشرات LED وأدوات القياس.
- `client/src/lib/simulation.ts`: المحرك العقدي وقراءات الأدوات وعينات الزمن.
- `scripts/validateSimulation.ts`: دارات التحقق المرجعية.
